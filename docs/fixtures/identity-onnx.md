# Synthetic identity ONNX fixture

The ONNX feasibility test builds a minimal graph in test code with small, test-only protobuf
structures rather than downloading or checking in model weights. The graph has one `FLOAT` tensor
input of shape `[1, 3]`, one `Identity` node, and one matching output. It was authored for this
repository from the public ONNX protobuf format and contains no third-party model parameters or
training data.

The generated bytes are test-only and covered by the repository's MIT OR Apache-2.0 license. The
test verifies exact output values, so successful loading alone cannot produce a false positive.

The ONNX engine integration tests generate a second graph with the same licensing and provenance.
It accepts dynamic-shape `INT64` token ids and attention masks, casts token ids to `FLOAT`, and
returns them as a deterministic sentence embedding. The accompanying WordPiece tokenizer is also
created entirely in test code from a seven-token synthetic vocabulary, serialized as ordinary
tokenizer JSON, and written only to a temporary directory. This fixture has no downloaded weights,
training data, executable model code, or dependency on network access. It is intentionally not a
quality model: it proves the production loader, tokenizer, input construction, ONNX execution,
batch padding, normalization, prefix, truncation, dimension, and lifecycle paths offline. The test
imports the generated artifacts through the production model store, obtains a verification-gated
load capability, initializes and warms the ONNX engine, and only then promotes infrastructure
health to ready.
