# Synthetic identity ONNX fixture

The ONNX feasibility test builds a minimal graph in test code with small, test-only protobuf
structures rather than downloading or checking in model weights. The graph has one `FLOAT` tensor
input of shape `[1, 3]`, one `Identity` node, and one matching output. It was authored for this
repository from the public ONNX protobuf format and contains no third-party model parameters or
training data.

The generated bytes are test-only and covered by the repository's MIT OR Apache-2.0 license. The
test verifies exact output values, so successful loading alone cannot produce a false positive.
